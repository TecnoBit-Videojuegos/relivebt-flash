# ReLiveBT Web Config

Páginas de configuración por **Web Bluetooth** para el adaptador **Re-Live BT Controller** de [TecnoBit Videojuegos](https://github.com/TecnoBit-Videojuegos/relivebt-flash). Desde tu navegador puedes mapear botones, cambiar opciones y gestionar tu adaptador, sin instalar nada.

🌐 **Configurador:** https://tecnobit-videojuegos.github.io/BlueRetroWebCfg/
🔄 **Actualizador de firmware:** https://tecnobit-videojuegos.github.io/relivebt-flash/
🧩 **Código del firmware:** [ReLiveBT-Controller](https://github.com/TecnoBit-Videojuegos/ReLiveBT-Controller)

---

## Requisitos

| Necesitas | Detalle |
|---|---|
| Navegador | **Google Chrome**, **Microsoft Edge** u **Opera** (PC o Android) |
| No compatible | Safari, Firefox y cualquier navegador en iPhone/iPad (no tienen Web Bluetooth) |
| Adaptador | Re-Live BT Controller encendido. Funciona con dispositivos cuyo nombre empieza con `ReLiveBT` o `BlueRetro` |

---

## Cómo usarlo

1. Enciende tu adaptador Re-Live BT.
2. Abre el [configurador](https://tecnobit-videojuegos.github.io/BlueRetroWebCfg/) en Chrome, Edge u Opera.
3. Pulsa el botón de conexión y elige tu adaptador en la ventana emergente del navegador.
4. Configura lo que necesites. Los cambios se envían al adaptador por Bluetooth.

> 💡 ¿Primera vez o quieres la última versión? Actualiza antes el firmware desde el [actualizador](https://tecnobit-videojuegos.github.io/relivebt-flash/).

---

## Problemas frecuentes

- **No aparece mi adaptador en la lista:** revisa que esté encendido, que ningún control esté conectado a él y que uses un navegador compatible.
- **Se desconecta o no responde:** apaga y enciende el adaptador, recarga la página y vuelve a conectar.
- **En iPhone no funciona:** es una limitación de iOS. Usa un PC o un Android con Chrome.
